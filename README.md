# Capital Defence — сайт юридического агентства (Пенза)

Статический сайт без сборщиков и зависимостей: HTML + CSS + немного JS.

## Структура

```
index.html              главная
komanda/                раздел «Команда» (index + страница каждого адвоката и юриста)
advokaty/, yuristy/     прежние адреса, только страницы-переадресации
materialy/              статьи адвокатов и юристов
dokumenty/              политика, положение и согласие по 152-ФЗ
assets/style.css        все стили (дизайн-система в :root)
assets/site.js          мобильное меню и форма заявки → Telegram
assets/fonts/           Onest (вариативный, локально, без Google Fonts)
assets/img/             фото, эмблема, favicon, og.png (превью для Telegram и соцсетей)
tools/build.py          сборщик страниц из общего шаблона (данные услуг, команды и статей внутри)
tools/old_articles.json кэш исходных текстов статей для сборщика
sitemap.xml, robots.txt
```

## Пересборка страниц

Все страницы генерируются из `tools/build.py`: шапка, подвал, услуги, карточки команды и статьи
описаны там один раз. После правки данных или шаблона выполните из корня:

```
python3 -I tools/build.py "$PWD"
```

Стили (`assets/style.css`) и скрипт (`assets/site.js`) сборщик не трогает, их правят напрямую.

## Локальный просмотр

Внутренние ссылки ведут на «чистые» адреса (`/advokaty/`, `/materialy/`), поэтому
открывать файлы двойным кликом не нужно — запустите любой статический сервер из корня:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000/.

## Как добавить специалиста или статью

- Специалист: скопируйте любую страницу из `advokaty/` или `yuristy/`, замените текст,
  фото (`assets/img/`, вертикальное 3:4, ~700×1050) и контакты; добавьте карточку
  в `advokaty/index.html` или `yuristy/index.html`, в блок «Команда» на главной и в `sitemap.xml`.
  Если фото нет — вместо `<img>` используется блок `<div class="monogram">ИФ</div>`.
- Статья: скопируйте любой файл из `materialy/`, замените заголовок, описание, текст
  внутри `<div class="prose">` и ссылки «предыдущий/следующий»; добавьте строку в
  `materialy/index.html`, на страницу автора и в `sitemap.xml`.

## Что нужно заполнить перед публикацией

- Реквизиты оператора, почта и дата утверждения документов заданы константами в начале `tools/build.py` (ORG_*, PD_EMAIL, PD_DATE).
- Постоянный номер телефона (сейчас везде один общий номер, заменяется поиском по `+79530236803`).
- Ссылки на личные чаты в Max (константа `MAX` и поле `max` у людей в `tools/build.py`): у Max нет ссылки по номеру телефона, нужна персональная ссылка из приложения.
